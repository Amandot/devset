How DevSet detects your tech

  
Every clue adds points. Enough points and a technology is confirmed; a few points and it is only possible. Tick the files your project has.

  

    

    
Bars show the score. Marks show the "possible" and "confirmed" lines for each technology.

  






  
Lockfiles decide the install command

  
DevSet uses your lockfile so everyone installs the exact same versions. Two lockfiles in one folder is a conflict, and DevSet warns you.
